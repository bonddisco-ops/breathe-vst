# Breathe

Analog color processor by Primal Rage Lab. Four bands, one knob each: tube, tape, transformer,
optical compression, a Dolby A style lift of quiet details and a Pultec curve at 10 % depth,
all under one knob per band. LIN switches the crossovers and the Pultec curve to linear phase.

Builds (Windows VST3 + Standalone, macOS VST3 + AU + Standalone) come from GitHub Actions and are
published to the `latest` release.
